# Vendored: Curve25519 (from noise-java)

`crypto/Curve25519.java` is a vendored copy of the pure-Java X25519 implementation from
[rweather/noise-java](https://github.com/rweather/noise-java), used by the v10+ encrypted
transport (`dev.spiegl.flyingcarpet.Noise*`; see `docs/shared-network-crypto.md`).

- **Source:** https://github.com/rweather/noise-java
- **Commit:** `49377b6dfc6a1e75740bce2318118291a57c0d6e`
- **License:** MIT (see `LICENSE.txt`)

## Why only this one file

We hand-roll the Noise `NNpsk0` handshake and transport in Kotlin
(`dev.spiegl.flyingcarpet.Noise.kt`) because:

- rweather/noise-java as a whole implements the **deprecated pre-2018 PSK scheme**
  (`NoisePSK_` prefix, no `psk0` token), which is **not interoperable** with the modern
  `Noise_NNpsk0_25519_ChaChaPoly_SHA256` that the Rust core (`snow`) and the Apple port use.
- The modern Java library (jchambers/java-noise) requires Java 17 and JCA `X25519`
  (Android API 30), but this app is `minSdk 29` / Java 8.

Everything except X25519 is available from the platform: ChaCha20-Poly1305 (JCA, API 28+),
HMAC-SHA256 and SHA-256 (JCA). X25519 via JCA (`XDH`) needs API 30, so we vendor this
self-contained pure-Java scalar-multiplication routine, which runs on API 29 and Java 8.

The hand-rolled handshake is verified byte-for-byte against the official Noise test vector
(cacophony) and the Rust app KATs in `NoiseUnitTest.kt`.

Do not edit this file. To update, re-copy `Curve25519.java` from a newer commit.
